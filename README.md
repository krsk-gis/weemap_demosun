Közösségi PGIS térképező alkalmazás (a [weemap](https://github.com/krsk-gis/weemap) módosított, demó változata), amellyel Szegeden felmérhetők a legforróbb és a leghűvösebb pontok.

A felhasználó két pontot helyezhet el a térképen:

- 🔆 egy **forró pontot** (napocska ikonnal),
- ❄️ egy **hűvös pontot** (hópehely ikonnal),

mindkettőhöz opcionálisan szöveges indoklást is fűzhet (miért pont azt a helyet választotta). Beküldés után egy rövid demográfiai kérdőív következik (kor, nem, lakhely). A korábbi beküldők eredményei szándékosan nem jelennek meg a térképen.
